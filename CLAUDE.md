# Project context

This is a teaching repo: a parent teaching data science and machine learning to their daughter. All modules are AI-generated.

## Guidelines for generating content

- Audience is a beginner learner — explain concepts simply, define jargon on first use, and prefer intuition and visuals over math notation.
- Keep lessons short and hands-on; every concept should come with runnable code the learner can tweak.
- Use scikit-learn, pandas, numpy, and matplotlib.
- Each module goes in `modules/NN-topic-name/` with `README.md` (lesson), `notebook.ipynb` (runnable code), and `exercises.md` (practice problems, easiest first).
- Use small, relatable datasets (place them in `datasets/`) — real-world topics like weather, sports, music, or animals work well.
- Modules should build on earlier ones; state prerequisites at the top of each lesson.
