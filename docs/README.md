# docs/ — reference material for the course

Everything here is reference: it belongs to no single module and stays useful throughout. The modules themselves live in [`../modules/`](../modules/).

## What's here

| File | What it is | When to read it |
|---|---|---|
| [the-big-picture.md](the-big-picture.md) | What AI / machine learning / deep learning actually are, supervised vs unsupervised, classification vs regression, the train/test idea, and a map of the whole course | **First** — before Module 04 |
| [curriculum.md](curriculum.md) | The full roadmap: every module's dataset, story, and notebook arc, from pandas to the malaria-detector capstone | Early, then whenever you wonder what's next |
| [glossary.md](glossary.md) | Every jargon term in the course, A–Z, in plain language — each with a biology analogy | Keep open in a tab; look up terms as they appear |
| [cheatsheets/pandas.md](cheatsheets/pandas.md) | One-page pandas reference: load, inspect, filter, groupby, merge, pivot, dates, plot | Mid-exercise, Modules 02–03 onward |
| [cheatsheets/sklearn.md](cheatsheets/sklearn.md) | The split → fit → predict → score workflow, which model for which problem, metrics, Pipeline + GridSearchCV | Mid-exercise, Modules 04–08 onward |
| [cheatsheets/pytorch.md](cheatsheets/pytorch.md) | Tensors, the training-loop liturgy annotated line by line, `nn.Module`, devices | Mid-exercise, Modules 09–11 and capstone |

## Suggested reading order

1. [The big picture](the-big-picture.md) — the map, before any machine learning.
2. [The curriculum](curriculum.md) — skim it once so you know the shape of the journey.
3. Everything else on demand: the [glossary](glossary.md) when a term is fuzzy, the cheat sheets when you can't remember how to write something.

## About the figures

`images/` holds the figures the docs embed. They are all generated by [`make_figures.py`](make_figures.py) — to regenerate them:

```bash
cd docs
../.venv/bin/python make_figures.py
```
